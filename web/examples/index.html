@shashank1010/rhp-web examples

rhp's charts as custom elements: the chart is markup, and the row is a slat. Each page has three tabs, one per way of writing slats: Template (markup with {path} bindings), h (function calls) and html (tagged templates), each drawing the same chart. Per chart, the editor holds the chart's markup and its slats as the selected tab writes them, marks what the tab adds to what every tab shares, and the page beside it redraws as you type; a link to bar.html#template opens that tab.

  • bar.html: the README's bar chart, <rhp-chart> and <rhp-plot> with JSON column attributes, order="sortBy:pounds:desc", a tick slat, and the same slat on other rows, thinner from the plot's template.
  • live.html: data as properties (plot.data, then plot.sold every second), animate, static toggled by a button, keyboard, and a readout from the focused row's $row().
  • scatter.html: <rhp-many-dots> with field names, key, color and size accessors, <rhp-scale> with a tick slat and <rhp-axis ticks="every:…">.
  • blocks.html: slats made of block elements (rhp-bar, rhp-label, rhp-tick, rhp-place, rhp-cell, rhp-dot), an <rhp-area> and <rhp-line> sparkline per row, shape() as a property, and a slat written as a class extending RhpSlat.
  • poster.html: two <rhp-poster> looks from posters.css, each under an <rhp-theme>, with slotted parts: the medal table stacked by gold, silver and bronze, and Tokyo to Paris.
  • csp.html: the fruit chart under a strict Content-Security-Policy (a nonce, no 'unsafe-eval'): its h and Template tabs draw, and its html tab shows what the policy refuses.
  • react.html: React 19 rendering <rhp-chart> and <rhp-plot> with properties, the chart following useState (one page, no tabs).
